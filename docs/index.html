Built with an SRE Mindset

Most Markdown renderers break down on complex tables, drop raw escape codes, or crash when piped. mdee is architected from the ground up for stability and terminal aesthetics.

🖼️

Native Inline Images (OSC 1337)

Renders PNG, JPEG, GIF, WebP, and SVG images directly inside your terminal grid using the iTerm2 OSC 1337 graphics protocol. Supports remote HTTP URLs, local file paths, and Base64 data URIs with automatic cell-height dimension constraints and graceful terminal-width fallback cards.

$ mdee --image-width 80 --image-height auto architecture.md
🧜‍♀️

Native Mermaid Diagrams

Renders flowcharts, sequence diagrams, and state machines graphically via iTerm2 OSC 1337 and Kitty protocols. Features Catmull-Rom 2x HiDPI resampling, automated background contrast cards (fixing dark/light terminal blend), and graceful cascading fallback to Unicode box-drawing or pure 7-bit ASCII text art.

$ mdee --mermaid auto --mermaid-bg dark architecture.md
🔗

OSC 8 Clickable Links

Terminal links render as native OSC 8 clickable hyperlinks. Hold Cmd and click any link to open the target URL directly in your browser without cluttering terminal output.

[GitHub](https://github.com/smford/mdee)
📊

Unicode-Aware Responsive Tables

Uses Unicode grapheme cluster segmentation (uniseg) to accurately compute visual column widths for emojis, variation selectors, and East Asian characters. Dynamically allocates column budgets and wraps text at word boundaries without clipping.

$ mdee -w 80 --table-style rounded sla-matrix.md
🎨

Chroma Syntax Highlighting

Automatic language detection and TrueColor syntax highlighting across 200+ programming languages. Features rounded framed enclosures, optional line numbers, and built-in themes: Dracula, Monokai, Solarized Dark/Light, and Standard Dark/Light.

$ mdee --theme dracula -n script.py
🛡️

Broken Pipe Resilience (EPIPE)

Piping into head -n 5 or grep terminates gracefully without Go runtime panics, stack traces, or broken pipe crashes.

📜

Built-In Pager Integration

Seamlessly route long documentation through your favorite terminal pager (less -R -F -X) using --pager.

⚡

Scripting Plain Output

Use --plain to strip all ANSI escape sequences, borders, and colors for seamless parsing in automated bash/awk pipelines.

⚙️

Persistent Config (~/.mdeerc)

Auto-loads ~/.mdeerc in YAML or JSON, or point to custom config files with -c / --config.

Command-Line Interface

CLI Flags & Configuration

Tailor width constraints, themes, borders, and image behaviors to your workflow.

Flag Shorthand Default Description
--config -c "" Custom config file path (auto-loads ~/.mdeerc if present)
--width -w 0 (auto-detect) Explicit terminal width constraint in columns (e.g. -w 80)
--theme -t "dark" Syntax theme: dark, light, dracula, monokai, solarized-dark, solarized-light, plain
--table-style -s "rounded" Border style: rounded, box, double, ascii, markdown, minimal
--images -i "auto" Inline image rendering: auto (iTerm2 only), always, never
--image-width — "auto" Image column constraint: auto, 100%, 80, 400px
--image-height — "auto" Image height constraint: auto, 20, 300px
--mermaid -m "auto" Mermaid render mode: auto, image, ansi, unicode, ascii, raw
--mermaid-theme — "" Mermaid theme: dark, default, slate, blueprint, neon, neutral, forest
--mermaid-width — "auto" Mermaid display width constraint: auto (responsive cell-fit), 100%, 80, 800px
--mermaid-bg — "auto" Mermaid background canvas: auto, dark, light, transparent, #RRGGBB
--mermaid-scale — 2.0 HiDPI rasterization scale factor (1.0 - 4.0 for Retina sharpness)
--line-numbers -n false Display line numbers in code blocks
--hyperlinks — true Enable OSC 8 clickable terminal hyperlinks
--pager — false Route output through interactive pager ($PAGER or less -R -F -X)
--plain — false Strip all ANSI escapes and borders for clean scripting pipelines
--debug — false Emit SRE diagnostic log traces to stderr
Get Started

Installation Options

Choose the package manager or build method that matches your environment.

🍺 Homebrew Tap (Recommended)

Directly install pre-built binaries for macOS (Apple Silicon & Intel) or Linux via custom tap:

brew install smford/tap/mdee

To upgrade later: brew update && brew upgrade mdee

🐹 Go Toolchain

Compile and install the latest tagged binary directly into your $GOPATH/bin:

go install github.com/smford/mdee/cmd/mdee@latest

Requires Go 1.24 or newer.

🛠️ Build From Source

Clone the repository and build using the dynamic Git-aware Makefile:

git clone https://github.com/smford/mdee.git cd mdee make build # Binary at ./bin/mdee

Runs full suite via make test-race.
